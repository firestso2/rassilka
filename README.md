# SpamBot — Telegram Userbot Рассылка

## Установка на VPS (Ubuntu/Debian)

```bash
# 1. Клонируй/загрузи файлы
mkdir /opt/spambot && cd /opt/spambot

# 2. Создай виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# 3. Установи зависимости
pip install -r requirements.txt

# 4. Настрой конфиг
cp .env.example .env
nano .env  # заполни BOT_TOKEN и ADMIN_IDS

# 5. Запусти бота
python bot.py
```

## Установка как systemd-сервис (автозапуск)

```bash
cp spambot.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable spambot
systemctl start spambot

# Логи
journalctl -u spambot -f
```

## Использование

### 1. Добавить аккаунт для рассылки
1. Нажми **📱 Аккаунты** → **➕ Добавить аккаунт**
2. Введи **API ID** и **API Hash** с https://my.telegram.org
3. Введи номер телефона → получи код → введи код
4. Аккаунт добавлен и сразу готов к работе

### 2. Запустить рассылку по чатам
1. Нажми **📢 Флуд по чатам**
2. Выбери аккаунт
3. Введи чаты (по одному на строку: @username, ссылка или ID)
4. Укажи количество повторений и задержку
5. Напиши текст рассылки
6. Задай период остановки или пропусти

### 3. Рассылка по папке Telegram
1. Нажми **📁 Флуд по папке**
2. Выбери аккаунт → выбери папку из списка
3. Остальные шаги как у обычного флуда

### 4. Управление задачами
- **📋 Задачи** — список активных рассылок
- Пауза / Продолжить / Стоп — кнопки у каждой задачи

### 5. Удалить сообщения
Команда: `/del [acc_id] [chat] [количество]`  
Пример: `/del 1 @mychat 20`

## Спин-текст

Синтаксис: `?$(вариант1|вариант2|вариант3)`

При каждой отправке бот случайно выберет один из вариантов.

**Примеры:**
```
?$(Привет|Хай|Здарова), как дела?
Хочешь ?$(заработать|получить) ?$(деньги|доход)?
?$(🔥|💥|⚡️) Горячее предложение!
```

## Период остановки (МСК)

При создании рассылки можно задать временной диапазон, когда рассылка автоматически **приостанавливается**.

Формат: `HH:MM-HH:MM`

Примеры:
- `23:00-09:00` — стоп с 23:00 ночи до 09:00 утра
- `13:00-15:00` — стоп с 13:00 до 15:00

В указанное время бот ждёт, затем возобновляет рассылку автоматически.

## Важные замечания

- Не ставь задержку `0` — Telegram быстро банит за флуд
- Рекомендуемая задержка: **3–10 секунд** между сообщениями
- Аккаунты хранятся в зашифрованном виде (StringSession) в SQLite
- Один аккаунт может вести только одну задачу одновременно
